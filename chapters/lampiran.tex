\subsection*{Lampiran 3: Skrip Instalasi Otomatis Multi-Platform}
\addcontentsline{toc}{subsection}{Lampiran 3: Skrip Instalasi Otomatis Multi-Platform}

Perintah instalasi instan untuk pengguna akhir:
\begin{itemize}
    \item \textbf{macOS dan Linux (Bash):}
    \begin{verbatim}
    curl -fsSL https://crootagent.github.io/install.sh | bash
    \end{verbatim}
    \item \textbf{Windows (PowerShell):}
    \begin{verbatim}
    irm https://crootagent.github.io/install.ps1 | iex
    \end{verbatim}
\end{itemize}
